# 昼休みの宇宙戦争・危険宙域編 — HAZARD ZONE

▶ **遊ぶ: https://katomi95.github.io/houi-toppa-3/**

「昼休みの宇宙戦争」シリーズ第3作。操作・艦隊の挙動・戦闘は前作までのまま、戦場そのものが危険になる。
どの危険を受け入れ、どの危険を避けるか。上達するのは操作ではなく、戦場を見る目。

## 操作（前作と同じ）

| 操作 | キー |
|---|---|
| 方向転換 | ← → （A D） |
| 前進 | ↑ （W） |
| 後退（低速） | ↓ （S） |
| 一時停止 | P / Esc |
| 消音 | M |

攻撃は自動。射程内の敵を撃つ。新しい操作・武器・特殊能力はない。

## 作戦

| STAGE | 任務 | 考えること |
|---|---|---|
| 1 砲撃圏 | 制限時間内にレーザー砲台を破壊 | 射線のどちら側から、いつ近づくか |
| 2 機雷帯 | 集結地点へ到達 | 機雷原を突っ切るか、守備隊のいる迂回路か。後ろから敵主力が来る |
| 3 落下軌道 | 質量弾を防衛ライン到達前に破壊 → 後退 | 護衛の薄い方向から張り付き、居座る |
| 4 主力艦隊 | 同規模の敵主力をかわしてレーザー砲台を破壊 | 敵主力を射線や友軍へ向けさせる |
| 5 危険宙域 | 大質量弾を最終防衛ライン到達前に破壊 | 敵主力・掃射レーザー・機雷原・友軍、全部を読む |

敵主力艦隊を倒す必要はどの作戦にもない。

## 危険

- **巨大レーザー砲台** — 動かない。充填ゲージが一周すると長射程・高威力のレーザーを撃つ。
  次に撃つ方向は橙の薄い警告帯で示され、発射が近いほど濃くなる（残り秒数も射線上に出る）。
  固定射撃と、約6度を薙ぐ掃射の2種類。**敵にも友軍にも当たる**。岩や質量弾に当たるとそこで止まる。
  持ち場にいる敵は発射前に射線から退くが、戦闘中・追撃中の敵は退かない
- **質量兵器** — 巨大・高耐久・低速。反撃しない。進路と防衛ライン到達予定地点が点線で出る。
  破壊するには横に張り付いて撃ち続けるしかない
- **機雷原** — 橙の斜線の区域。中にいる艦は0.5秒ごとに一定確率で沈む（敵味方とも）。
  即死ではない。通り抜けられる
- **敵主力艦隊** — 自艦隊と同じ性能・ほぼ同じ規模。点線の輪と名前・残存数で表示。
  広く見張り、近い相手（友軍を含む）に食いつく。正面から殴り合えば双方が大きく損耗する

## ルール（前作から変わらないもの）

- 自艦隊・敵艦隊・敵主力の前進速度はすべて同じ。後退は遅い。速さで逃げ切ることはできない
- 交戦中は足が止まる（敵主力と接触すると特に強く捕まる）
- 自艦隊が出撃数の 15% を下回るか、5秒間包囲されると失敗

## 画面の見方

- 水色：自艦隊　緑：友軍　赤：敵艦隊（大きめの艦と点線の輪は敵主力）　桃色：TARGET
- 橙の帯：レーザーの射線（警告）　橙の斜線：機雷原　黄の破線：目的地点　青の破線：防衛ライン
- 上中央にレーザー発射までの秒数と質量兵器の到達までの時間。数字は補助で、危険は盤面の位置と形で読む
- 左上：任務と残り時間　右上：自艦隊・友軍・敵主力の残存。下に艦隊や砲台が入ると薄くなる

## 演出

平常時は静かな戦術画面。レーザー発射・質量兵器破壊・敵主力との接触・最終防衛ライン目前・任務成功直前だけ、
閃光・画面の揺れ・赤い縁・上下の帯で一瞬だけ映画のようになる。航跡・エンジン噴射・旋回時の個艦の遅れは見た目だけで、挙動は変えていない。

## 技術

HTML / CSS / JavaScript のみ。ビルド不要、外部依存なし。`index.html` を開けば動く。

- `js/core.js` — シミュレーション（前作の艦隊 AI・戦闘・任務管理に、レーザー砲台・質量兵器・機雷原・敵主力艦隊とステージ定義を追加）
- `js/game.js` — 描画・入力・画面遷移・HUD・演出
- `js/audio.js` — WebAudio による効果音（前作の音に、レーザー・機雷・衝撃・秒読みを追加）

URL に `#debug` を付けると `window.__game` からコマ送りできる（検証用）。
